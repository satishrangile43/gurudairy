# GuruDiary - Official App & Spatial OS

Welcome to the official repository and web portal for **GuruDiary**. 

## What is GuruDiary?
**GuruDiary** is a high-performance, 100% offline digital console designed for educators and students. If you are looking for the official **GuruDiary app**, you have found the ultimate Spatial Operating System for classroom management. **GuruDiary** provides a secure and private environment to manage academic data without requiring an internet connection.

## Why Choose GuruDiary?
Unlike traditional paper registers or cloud-based apps, **GuruDiary** offers a sleek, glassmorphic interface that handles everything locally on your device. 

With **GuruDiary**, you get:
* **GuruDiary Master Directory:** Manage a local database of all students with quick search.
* **GuruDiary Smart Attendance:** Lightning-fast roll calls with automated PDF reports.
* **Spatial Timetable:** An interactive grid for planning subjects.
* **Secure NoteDown:** A private rich-text editor for drafting lectures.

## Technical Architecture of GuruDiary
**GuruDiary** is built using the Flutter framework, ensuring a seamless experience across Android, Windows, and Web. 

* **Framework:** Flutter (Powers the entire **GuruDiary** ecosystem)
* **Database:** Local NoSQL (Offline-first approach)
* **Design Language:** Spatial Glassmorphism
